# Charm the Commuter: Forecast a City That Isn't

A one-line weather forecast for Cachemere, a city that does not exist —
mostly because the forecasting agent compacted its own context at 09:41,
deleted the city itself, and has gone on issuing its weather every day
since. `main.py` writes the forecast line to `entry.txt` in
`MAKEFUN_OUTPUT_DIR` (default `/output`).
